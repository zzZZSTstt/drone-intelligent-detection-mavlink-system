# 目标检测与跟踪系统

一个基于TensorRT加速的实时目标检测与跟踪系统，支持与无人机等设备通过Mavlink协议通信，适用于ARM和x86平台。

## 功能特点

- 基于TensorRT的高性能目标检测，支持YOLO系列模型
- 自动适配ARM/x86平台，优化性能参数
- 支持RTSP视频流输入处理
- 通过Mavlink协议与无人机等设备通信
- 内置PID控制器实现目标跟踪功能（云台/飞行跟踪）
- 完善的日志系统，支持日志切割和级别管理
- 可配置的检测参数，适应不同场景需求
- 图像增强功能，提升复杂环境下的检测效果
- 优雅的退出机制和错误处理

## 环境要求

### 硬件要求
- x86平台：支持CUDA的NVIDIA显卡
- ARM平台：Jetson系列（Nano/Xavier等）或其他支持TensorRT的ARM设备
- 网络环境：能访问RTSP视频流（如无人机相机）
- 串口：用于Mavlink通信（如无人机Eport）

### 软件要求
- Python 3.6+
- TensorRT 7.0+
- CUDA 10.2+
- OpenCV 4.0+
- PyCUDA
- pymavlink
- numpy
